## 给普通用户

下载完整 UI 包并解压，按 [从这里开始](../../../START_HERE.md) 双击首次配置和启动向导。新建、审阅、结果检查、意见记录和报告导出都在页面完成，不必应用代码补丁。

## 给接手维护者

先读使用说明，在 local 模式复现，再查看测试证据。执行器和规格变动会使旧计划失效，修改后需要新建计划。安装复制不覆盖现有目录。

如收到本项目代码补丁，请在原始资料提交 `2b5666c445237779f179d1e27ad23c08f069980d` 或兼容的干净工作区中先做 `git apply --check`，审阅后应用。补丁只提供可审阅变更，不会自动推送或上线。

正式提交或真实 GitHub 联调时，还需确定接收仓库、分支或 PR 方式并完成账号授权；这不影响查看代码、阅读说明和本地试用。
