# 0.6.0 恢复与可用性改进测试

UI 0.6.0，执行器 0.3.1。对应 [Windows 真实试用问题](trial-009.md)。本记录为维护者在 Linux 上执行的自动化测试；不代表修复版已通过 Windows 真人验收或公司资产云联调。

## 已修改

- 每步保存文件归属与内容摘要；中断恢复保留此前清单，拒绝混入额外文件及用户修改后的内容。
- 新增专用补交方案：原计划已完成、新建总入口仅残留模板 LICENSE 时，复核账号、仓库身份、提交与文件内容，展示后确认；仅新增 LICENSE 提交，不修改原计划、批准或执行日志。
- 推送响应丢失后，补交按父提交、提交说明、仅 LICENSE 的差异和远端 HEAD 核对后继续，不重复创建提交或强推。
- 核验结果区分通过、发现问题、无法核验；失败项附仓库和时间。只读 git ls-remote 有限重试，创建与推送不自动重试。
- 创建进度与逐项核验进度分开，显示实际仓库与时间；补交另有记录。
- 所有页面可查看记录位置；单击导出经过字段筛选和凭据清理的诊断 ZIP，避免手动找文件夹。诊断不包含需求正文、规则全文或仓库文件。
- 保留命名提示、标准对照、账号范围确认、重复创建及历史记录；更新升级与非技术验收说明。
