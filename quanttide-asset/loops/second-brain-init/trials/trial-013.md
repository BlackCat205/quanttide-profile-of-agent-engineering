# 0.7.0 中断恢复测试记录

日期：2026-09-09。UI 0.7.0，执行器 0.4.0。测试环境 Linux；未进行真实 GitHub 写入或 Windows 实机验收。

## 修改

- 记录远端创建、下载、文件生成、暂存、提交、推送阶段；保存中间检查点、仓库身份和工作流文件归属。
- 下载在 downloads 下独立目录进行，成功后移入正式仓库路径并清理空尝试目录；失败残留保留，不删除未知文件。
- 已保存提交后响应丢失，只有远端等于已记录本地提交且其他状态无变化才接续；推送前再次判断是否已同步。
- 页面分别显示首次失败与最近检查，并显示阶段进度。
- 旧版 0.3.1（限定源码 SHA）中断于 ensure-repo，可只读核对初始仓库并由用户明确确认接续。仅允许一次提交、单一标准 README、正确所属账号与写权限、本地未下载、其他仓库不变。生成独立计划、审批及恢复日志，保留原始记录。
- 资产契约仅将技能版本更新为 0.4.0；格式与规则文件不变。没有重新宣称本版完成原生 Rust CLI 验收，原生证据仍见 trial-011。

## 验证边界及保留问题

创建成功但 API 响应完全丢失、网络在阶段检查点保存前中断、提交过程中断、已有目录残留或额外文件等情况仍安全暂停，不能无条件自动恢复。没有改动用户 sample3 仓库或电脑文件。本版加入了受限旧任务接续能力，不代表用户实际恢复已成功；需按断网恢复说明操作并导出结果。
