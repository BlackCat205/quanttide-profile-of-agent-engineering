## 修改

- 规划已有总入口时，先记录默认分支提交，再通过已登录的 GitHub API 读取固定提交上的 README、AGENTS、`.gitmodules` 和三类 `.quanttide` 契约，不再为了审阅完整克隆仓库。
- 明确 404 的可选文件按不存在处理；连接失败、权限错误、限流、无提交或版本漂移仍停止规划。
- 无方案的暂停记录显示“重新生成方案”，在同一记录沿用原需求重新调查；不会建立新任务或重复输入。
- 无方案时禁用连接检测、继续执行和最终核验；即使绕过页面直接请求，也返回中文状态错误，不再泄露原始 `FileNotFoundError`。
- 直接使用技能 CLI 时仍保留原有只读克隆回退；执行阶段的真实文件传输、提交和推送不受此次优化替代。
