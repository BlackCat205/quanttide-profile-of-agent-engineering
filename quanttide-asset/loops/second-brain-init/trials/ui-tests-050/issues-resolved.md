# 本轮发现与处理的问题

- 新增许可和初始化文件起初未全部进入提交清单，领域和根仓库检查报工作区不干净。改为通过执行器的文件写入记录纳入提交。
- 初始化文件若放在通用 Provider.ensure 中，会改变已有维护场景的准备行为；已移到执行器的新建仓库步骤，保留既有许可和容器许可规则。
- 恢复测试原来假定每项操作只有一条事件。加入开始、失败事件后，改为验证每项完成事件唯一，且失败历史保留；不是删除失败记录。
- 授权界面异步响应需等待状态更新；补充取消后的请求版本检查，防止旧轮询覆盖取消结果。
- 测试环境旧浏览器缓存不可用，重新下载后完成浏览器检查。环境缺少中文字体，补齐测试字体后重新检查页面。未把这些 Linux 操作记作 Windows 真人验收。

最终结果分别保存在同目录的 Python 日志、浏览器 JSON 和测试范围声明中。
