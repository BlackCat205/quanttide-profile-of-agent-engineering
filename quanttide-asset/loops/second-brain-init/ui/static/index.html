    第一步

    你想建立什么领域？

    首次使用建议先体验“示例工程”。示例会创建真实的本地仓库，不会写入 GitHub。

    先了解真实 GitHub 现状（只读）

    填写本次需求后，可查询目标公开仓库和总目录。不创建仓库，不授权写入，不代表组织全部目录已检查。

    创建到哪里？

    连接你电脑上的 GitHub CLI。GPT 中的 GitHub 连接不会自动登录这个工具。

    先连接账号，再生成方案。

    打开 GitHub 官方授权页面
    安装 GitHub CLI（Windows，不需要打开 CMD）
    1. 打开官方下载页面，选择“Windows — Download MSI”，下载 .msi 安装包。
    2. 双击下载的文件，按安装向导完成安装（通常是 Next → Install → Finish）。
    3. 安装后关闭本工具的启动窗口和旧页面，再双击“启动向导.bat”。只刷新网页不能让已运行的程序识别新安装的软件。
    4. 重新选择“个人 GitHub”，点击“检查登录状态”。如果显示尚未登录，再点“连接 GitHub”完成官方授权。
    装好后仍提示缺少？

    新打开 CMD（按 Win + R，输入 cmd 后回车），输入 gh --version 并回车。显示版本号表示安装可用；若提示不是内部或外部命令，尝试重启电脑后再打开工具，仍不行请提供提示文字。

    本轮只支持当前登录者的个人公开仓库。第一次新建入口共创建 8 个仓库；后续创建 7 个并更新已有入口。请使用测试内容。登录成功不代表创建和推送已经测试通过。

    先生成方案，确认后才创建。

    核对这份创建方案

    检查名称、用途和资料位置。这里的“仓库”是带修改历史的项目文件夹。

    创建前对照检查

    “符合”仅表示列出的检查通过；仓库是否创建成功，将在执行后另外验证。

    查看现有仓库的规则与说明

    若复用已有仓库，请确认现有约定允许本次修改。程序不会自动理解全部组织规则。
