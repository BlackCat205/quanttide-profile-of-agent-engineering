启动前检查

这页随压缩包提供，双击即可查看，不需要先安装 Python。

1. 准备两个软件

  • Python 3.10 或以上：Python 官方下载。安装时确认包含 venv 和 pip。
  • Git 2.28 或以上：Git 官方下载。Linux 用户可按页面中的发行版说明安装。

已经安装过？直接运行下一步的首次配置脚本，脚本会检查版本并指出缺少什么。

2. 首次配置与日常启动

Windows：先双击 首次配置.bat，完成后双击 启动向导.bat。

Linux / macOS：在本文件所在文件夹打开终端，依次运行：

  1. sh ./首次配置.sh（只需首次运行，需联网）
  2. sh ./启动向导.sh（以后用这条启动）

创建到 GitHub 时

还需安装 GitHub CLI，并在终端运行 gh auth login。只体验本地创建可跳过。

目前已在 Linux 验证本地创建流程；macOS 和真实 GitHub 创建流程仍待实机验证。
